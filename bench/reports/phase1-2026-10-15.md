# Phase 1 benchmark report — curves and surfaces (B1.1–B1.5)

**Date:** 2026-10-15
**Status:** interim report towards the v0.1 gate; a CI-hosted run on the reference Linux image is still to come.

## Setup

| | |
| --- | --- |
| Harness | `bench/occt/OcctBench.cpp` (`stereon_occt_bench`), Google Benchmark, 5 repetitions, medians of CPU time |
| Stereon | branch `bench/occt-phase1`, GCC 16.2.0 (MSYS2 UCRT64), `-O3 -DNDEBUG`, contracts ignored, hot contracts off |
| OCCT | 8.0.1, tag `V8_0_1`, commit `b8f597c`, built by `tools/occt/build_occt.sh` with the same compiler, `-O3 -DNDEBUG` |
| Machine | Intel Core i5-10210U (4 cores, 1.6 GHz base), 8 GB, Windows 11; a laptop, single-threaded runs, timings carry a few percent of noise |

Each Stereon benchmark has an OCCT twin on the same geometry. OCCT gets its best usage where it has one: projections reuse an initialised `GeomAPI_ProjectPointOn*` and call `Perform`, as Stereon's reuse a `CurveProjector` or `SurfaceProjector`; evaluation with derivatives is one `D2`/`D1` call against one `Derivatives` call; Bezier decomposition asks OCCT for every arc, since OCCT builds them on demand.

## Notes

- **Correctness gate.** The evaluation and projection results compared here agree with OCCT in the differential tests (`tests/occt/GeometryDifferentialTests.cpp`): values and derivatives to a relative 1e-13, projection distances to 1e-9, never farther than OCCT's.
- **Approximation is not like for like.** `Approximate` returns the fewest-pole least-squares cubic whose deviation at the points is within the budget; OCCT's `GeomAPI_PointsToBSpline` with `GeomAbs_C2` and the same tolerance optimises parameters and continuity as well. Both meet 1e-3 mm on this input, but the curves differ, and OCCT's extra work is part of its time. The deviation of each result is not yet compared in the harness; until it is, read the ratio as indicative.
- **History of this report.** The first run of the harness had Stereon 2.9–60× slower on derivatives and projection and 2.6× slower on Bezier decomposition. Three changes closed the gap: derivatives from differenced poles and one basis triangle, with work arrays sized to the degree; projectors that precompute the point-independent parts of the stationarity polynomials and search best-first; and single-pass Bezier extraction (The NURBS Book, A5.6). A first comparison also asked OCCT for its arc count only, while Stereon built every segment; the harness now has OCCT build every arc.
