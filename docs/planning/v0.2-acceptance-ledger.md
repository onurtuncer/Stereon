The line–line slice does not change v0.1 scope or the product version. Its
configuration and domain decisions use exact predicates on the nominal input
doubles and the model resolution, which decides whether two lines meet.
Numerical inputs outside the checked expansion domain fail explicitly;
automatic rescaling is not implemented. Overlap endpoints are outward-rounded
enclosures.

## Mandatory metamorphic release evidence (ADR-0053)

Run `python tools/check_metamorphic.py --release` and require the
**Intersection release evidence** workflow to pass before qualification.
The [machine-readable inventory](intersection-metamorphic.json) currently has
open historical obligations and untriaged handler relations: v0.2 is **not
qualified** by a passing development inventory check. See the
[backfill ledger](intersection-metamorphic-backfill.md) for evidence fields and
review requirements. The gate is additive to all existing numerical, CI,
performance and owner-review requirements.
