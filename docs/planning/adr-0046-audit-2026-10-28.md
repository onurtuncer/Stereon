# ADR-0046 audit: ownership, borrowing and pointer lifetimes

**Baseline:** `main` at `1776a52`, the revision ADR-0046's migration inventory names.
**Date:** 2026-10-28. **Scope:** `src/`, `tests/`, `bench/`, `python/`, as the ADR scopes itself; third-party sources excluded.
**Status:** the first disposition of the inventory. It records what was found, what this audit changed, and what stays open; it does not accept the ADR, which stays Proposed until the owner reviews it and the evidence below is complete.

## Method

Every area of the inventory was swept with targeted searches and the hits read:

- borrowed accessors (`Target<T>()`, `GetModel()`, `Get()`, `GetBasis()`, `GetProfile()`, `GetAxis()`, `GetSnapshot()`) and every call on an rvalue receiver (`).Target<`, `}.Target<`, `).GetSnapshot()`, `).begin()`);
- stored raw-pointer members (`T* m_...`) and `thread_local`/function-static state;
- controlled-edit callbacks (`Modify`, `ModifyPage`) and every dispatch of `ParallelFor`;
- manual lifetime and casts (`::new`, `const_cast`, `reinterpret_cast`, `std::launder`);
- exported functions returning `std::span`, `std::string_view` or pointers from module interfaces;
- the diagnostic registry and `stereon_describe_handle`;
- the Python bindings and the OCCT and CppAD adapters.

## Findings by section of the ADR

1. **Ownership separately from access.** Ownership lives in values, `std::vector`, `std::shared_ptr<const ...>` payloads and the snapshot token; no raw owning member was found. The two owner-internal raw pointers (`SmallBuffer::m_Model`, `PagedArena::ConstIterator::m_Arena`) are documented with their protocol.
2. **Lifetime contracts on escaping borrows.** Every exported `std::string_view` and `std::span` return is of static storage (enumerator names, capability catalogues). The borrowed member accessors now say what owns the storage and what invalidates the borrow. `SurfaceOf`, `CurveOf`, `PCurveOf` return owning wrappers, not references into the shape.
3. **No ephemeral storage through rvalue accessors.** Applied to `Target<T>()`, `GetModel()`, `SmallBuffer::Get()`, `GetBasis()`, `GetProfile()`, `GetAxis()`, `GetSnapshot()` and the ranges' `begin()`/`end()`. Source-breaking for six test sites, migrated here; no application code in the repository was affected.
4. **Edit callbacks.** The return-policy constraint now covers the direct borrowed forms. The mutation guard (`EditScope`, `IsEditing()`) was already active during a callback.
5. **Callback and worker boundaries.** `ParallelFor` joins before returning in both branches; the new test pins the exception path. Mutable scratch is per chunk (`ProjectionScratch`, #152) or per invocation.
6. **Manual lifetime and foreign interfaces.** One `const_cast` (`Records.cppm:529`) delegates a non-const accessor through its const overload, the permitted form; one `reinterpret_cast` (`GeometryArchive.cpp:1187`) is byte I/O with its extent, consumed synchronously. No `std::launder`, no manual `new`/`delete` pair outside `SmallBuffer`.
7. **Diagnostics.** See the registry row above.
8. **Enforcement.** The compile-time checks are in the test suites; the native sanitizer presets of CI (`gcc16-asan`, `gcc16-tsan`) run the new tests.

## Verification against the ADR's criteria

| Criterion | State after this audit |
| --- | --- |
| AC-0046-01 Interface inventory | The table above enumerates the borrowed results, stored observers and callback boundaries found, with their contracts in the interface comments; the one exception (the legacy debugger helper) is named. |
| AC-0046-02 Temporary borrowing | Compile-time tests accept lvalue inspection and owning temporary results and reject rvalue inspection, rvalue `GetSnapshot()` and iterator extraction from temporary ranges; `borrowed_range` is false for the ranges. |
| AC-0046-03 Retained lifetime | Partly: the existing `tests/topo/RangeTests.cpp` keeps a range alive after its shape; the `SmallBuffer` tests move owners while copies stay usable. Checked-instrumentation tests of documented invalidation are open. |
| AC-0046-04 Edit non-escape | Compile-time rejection of reference, pointer, span, string view and reference wrapper results. Callback failure and re-entrant edits are covered by the contract probes (`tests/probes/ContractProbe.cpp`); capture and store escapes were reviewed, not proven. |
| AC-0046-05 Parallel completion | The exception-path test; disjoint outputs and 1/2/8/32-thread identity are the existing determinism tests. TSan runs in CI's `gcc16-tsan` job. |
| AC-0046-06 Erased storage | The new `SmallBuffer` tests; they run under ASan and UBSan in CI's `gcc16-asan` job. |
| AC-0046-07 Concurrent diagnostics | The caller-buffer entry point and its concurrent test; concurrent lookup against snapshot release is open. |
| AC-0046-08 Foreign boundaries | Nothing to test until a binding exposes geometry; the C ABI of ADR-0020 is not built. |

## Open

- Checked-instrumentation tests that a documented invalidation (assignment, move, copy-on-write replacement) is detected rather than dereferenced (AC-0046-03).
- A concurrent test that a snapshot released during a description lookup is handled (AC-0046-07).
- The capture-escape review of edit callbacks is a standing review duty, not a one-time result.
- Owner review of the policy and acceptance of ADR-0046.
