# v0.1 "Geometry" acceptance ledger

**Owner:** Onur Tuncer
**Opened:** 2026-10-15
**Status:** open; no gate below is claimed as passed until its evidence is linked and reviewed.

The [roadmap](roadmap-and-versioning.md) asks for an acceptance ledger per release: for each gate, the supported domain, the ADR decisions it needs, the evidence, the implementation commit and the unresolved limitations. v0.1's scope is analytic and NURBS evaluation, fitting, projection and parameter-domain handling, with tolerances and approximation limits recorded and the declared geometry subset saved and loaded (M1/M4).

Statuses: **done** (implemented, tested, evidence linked), **partial**, **open**.

## Geometry operations compared with OCCT

What OCCT's `Geom`, `GeomLProp`, `GeomConvert` and `GCPnts` packages offer that a v0.1 user will expect, and where Stereon stands. Priority: **A** v0.1 blocker, **B** v0.1 if time allows, **C** later release.

| OCCT capability | Stereon | Priority |
| --- | --- | --- |
| Mirror about a point, axis or plane; rotation about an arbitrary axis (`gp_Trsf`) | done: `AboutPoint`, `MakeRotation(point, axis, angle)`, `MakeScaling(point, factor)`, `MakePointMirror`, `MakeAxisMirror`, `MakePlaneMirror`; `tests/core/MatrixTests.cpp`, `docs/geometry.rst` | A |
| Tangent, normal, curvature, principal curvatures, Gauss and mean curvature (`GeomLProp_CLProps`, `_SLProps`) | done: `UnitTangent`, `Curvature`, `PrincipalNormal`, `Torsion`, `CenterOfCurvature`; `UnitNormal`, `FundamentalForms`, `GaussianCurvature`, `MeanCurvature`, `PrincipalCurvatures`; `DegenerateResult` at singular points; `tests/{curve,surface}/PropertiesTests.cpp`, `docs/properties.rst` | A |
| Arc length, point at a length (`GCPnts_AbscissaPoint`) | done: `ArcLength` (adaptive Gauss–Legendre, reports `ErrorEstimate`), `ParameterAtArcLength` (safeguarded Newton, wraps periodic curves); `docs/properties.rst` | A |
| Trimmed curve, rectangular trimmed surface | conversion and B-spline restriction only | A |
| Surfaces of linear extrusion and revolution | conversion of the built-in surfaces of revolution only | A |
| Degree elevation, knot removal (`IncreaseDegree`, `RemoveKnot`) | none | B |
| Continuity and closedness queries (`Continuity`, `IsClosed`, `IsCN`) | none | B |
| Periodic B-splines (`SetPeriodic`) | represented unclamped | B |
| Curve concatenation (`GeomConvert_CompCurveToBSplineCurve`) | none | B |
| Offset curve and surface | none | C (v0.3: self-intersection and singularities) |
| Curve–curve, curve–surface extrema and intersections | dispatch stubs | C (v0.2) |

## Limitations carried into v0.1

- B-spline surface projection is certified in its exclusions, not inside its final sub-patches (`docs/nurbs.rst`).
- Fitted deviations are measured at the data points only (`docs/fitting.rst`).
- Benchmarks so far ran on one Windows laptop; the release report needs the CI reference image.
