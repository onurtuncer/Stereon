# v0.1 "Geometry" acceptance ledger

**Owner:** Onur Tuncer
**Opened:** 2026-10-15
**Status:** open; no gate below is claimed as passed until its evidence is linked and reviewed.

The [roadmap](roadmap-and-versioning.md) asks for an acceptance ledger per release: for each gate, the supported domain, the ADR decisions it needs, the evidence, the implementation commit and the unresolved limitations. v0.1's scope is analytic and NURBS evaluation, fitting, projection and parameter-domain handling, with tolerances and approximation limits recorded and the declared geometry subset saved and loaded (M1/M4).

Statuses: **done** (implemented, tested, evidence linked), **partial**, **open**.

## Limitations carried into v0.1

- B-spline surface projection is certified in its exclusions, not inside its final sub-patches (`docs/nurbs.rst`).
- Fitted deviations are measured at the data points only (`docs/fitting.rst`).
- Benchmarks so far are development runs on one Windows laptop. The release report must be a reference run from `.github/workflows/occt-reference.yml`, committed to `bench/reports/` with its machine record; until then no benchmark row above is release evidence.
