Geometric oracles, mutation testing and corpus replay
=====================================================

Analytic fixtures compute expectations independently of the handler. Metamorphic tests transform a known input and check how the result changes under rigid motion, scaling, operand exchange or a change of chart. A transformation alone cannot expose a shared wrong answer, so the tests also need geometric witnesses. Mutation replay first runs the baseline, introduces one historical fault, rebuilds, and repeats the selected tests. It records whether the intended diagnostic was observed. Fuzz and differential tests exercise different failure modes. Compiler reproducers, tooling checks, corpus generators and test-support code below implement the project-specific experiments.

Method references: :cite:p:`segura2016metamorphic,kettner2008classroom`.

Detailed treatment: :doc:`/testing`.
