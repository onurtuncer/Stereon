# Curve–curve corpus

Pairs of 3D curves with a known closest approach, generated by `tools/generate_curve_corpus.py`. Lint checks with `--check` that the files match the generator.

Each family is an unordered pair of the types line, circle, ellipse, parabola, hyperbola and cubic B-spline. In each case the second curve is translated so that its point at a stated parameter lies a stated gap from the first curve's point at its stated parameter, along their common normal. Those two parameters are then a critical point of the distance at exactly that gap, whichever curves they are.

| Case name | Gap, in resolutions (ADR-0001, 1e-5) | `expected.meets` |
| --- | --- | --- |
| `touching-*` | 0 | true |
| `within-*` | 0.4 | true |
| `beyond-*` | 1.5 | false |
| `apart-*` | 10 | false |

The claim of a case is local: the curves meet near `expected.parameters` exactly when `expected.meets` is true. A pair may also meet elsewhere.

`tests/intersect/CurveCorpusTests.cpp` runs every case in both orders. `tests/occt/IntersectionDifferentialTests.cpp` compares every case with OCCT's least distance between the curves.
